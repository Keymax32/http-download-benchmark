# HTTP Download Benchmark

Скрипт 10 раз подряд скачивает ресурс по указанному URL и измеряет скорость. Каждый замер начинается с GET-запроса и заканчивается после полного чтения ответа. Скрипт читает тело ответа порциями и не сохраняет его на диск.

## Запуск

Нужен Python 3.10 или новее. Все модули входят в стандартную библиотеку.

```sh
git clone https://github.com/Keymax32/http-download-benchmark.git
cd http-download-benchmark
python download_benchmark.py "https://www.python.org/"
```

Если Python запускается командой `python3` (например, на Linux или macOS) или `py` (на Windows), подставьте её вместо `python`. Для замера скорости на большом файле передайте прямой URL этого файла.

## Как считаются результаты

- **Среднее время запроса, с** — сумма времени 10 скачиваний, делённая на 10. Замер начинается перед открытием соединения и заканчивается после полного чтения ответа. Дополнительные HTTP-запросы при перенаправлении входят во время скачивания.
- **Общий объём, байт** — сумма размеров тел 10 ответов. Заголовки HTTP в объём не входят.
- **Скорость, МиБ/с** — общий объём в байтах, делённый на суммарное время запросов и на 1 048 576. Один мебибайт (МиБ) равен 1024² байтам.

При ошибке HTTP, обрыве или тайм-ауте скрипт печатает номер запроса и причину ошибки, затем завершает работу с кодом `1`. Тайм-аут сетевой операции составляет 30 секунд.
